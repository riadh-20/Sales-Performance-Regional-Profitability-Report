# Sales Performance & Regional Profitability Analysis

## 📊 Project Overview
This project involves a comprehensive analysis of a retail dataset containing over 9,000 transactions. The objective was to transform raw data into an executive-level dashboard to provide actionable insights into sales trends, product performance, and regional profitability.

## 🛠️ Tools Used
* **Microsoft Excel:** Data Cleaning, Pivot Tables, and Dashboard Design.
* **ETL Techniques:** Standardizing date formats, currency normalization, and duplicate removal.
* **Data Visualization:** Interactive charts including Time-Series, Categorical Bar Charts, and Regional Profit breakdown.

## 📈 Key Business Insights
* **Revenue Drivers:** The **Technology** category was identified as the primary revenue contributor, generating approximately 37% of total sales.
* **Regional Performance:** While sales are distributed across territories, the **West Region** demonstrated the highest net profitability ($108k+).
* **Seasonality:** Analysis of the monthly sales trend revealed significant peaks in **November and December**, suggesting high seasonal demand cycles.

## 📂 Project Structure
* `Sales_Performance_Dashboard.xlsx`: The core file containing the cleaned data, pivot calculations, and the final dashboard.
* `Dashboard_Screenshot.png`: A visual preview of the final reporting tool.

## 💡 How to Use This Dashboard
The dashboard is designed for executive stakeholders to quickly assess the health of the business. Users can view total KPIs at a glance and compare performance across categories and geographical regions to assist with inventory and marketing strategy.
